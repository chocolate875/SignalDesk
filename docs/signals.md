# 算子、因子与提醒口径

当前规则版本为 `fusion-1.1.0`，使用交易日日历检查日线缺口。输出附加当前规则配置的 SHA-256 短指纹，每个事件记录公式版本、数据时间和维度证据。分数描述技术结构。

## 数据前提

- OHLCV按UTC时间排序并去重；只使用明确已确认且结束时间不晚于当前时刻的K线。
- 当前工作台只采集常规交易时段日线。兼容回放的15分钟序列按 regular/pre/post/overnight 独立计算，避免把薄弱盘外量与盘中混算。
- 指标口径采用ta 0.11.0、fillna=False。ATR的前13根库前置零值额外屏蔽，零ATR视为不可用。
- 无效OHLCV和缺失的整交易日日线及同交易日内分时缺口会切断计算段并重新预热。缺数据不前向填充、不补零、不重新分配缺失维度权重。
- 最晚应完成K线由XNYS交易日历、时段和提前收盘规则计算；超过90秒容差的缺口标为过期。实时关键价还要求报价时间在最近120秒内。
- 半日盘盘后采用17:00纽约时间的本机保守日历边界；具体证券可用性以LongPort推送与权限为准。SDK返回的交易日/半日盘信息另外保存在本机，可供核对。

## 白名单算子

`delay(x,n)`、`delta(x,n)`、`returns(x,n)`只允许正整数历史窗口；`mean/std/min/max`要求完整窗口，标准差使用ddof=0；`ts_rank`采用平均秩百分位；`zscore`在零方差时返回NaN；`corr`按相同时间索引对齐；`clip`限制输出范围。不提供eval、动态导入和任意脚本执行。

## 默认融合公式

记 `clip(x)=min(1,max(-1,x))`，每个原始维度位于[-1,1]，映射为 `D=50*(1+d)`：

```
t1 = clip((EMA20 - EMA50) / ATR14)
t2 = clip((EMA20 - delay(EMA20, 5)) / ATR14)
t3 = sign(close - MA200)
trend_raw = (t1 + t2 + t3) / 3

m1 = (RSI14 - 50) / 50
m2 = clip(MACD_hist / ATR14)
momentum_raw = (m1 + m2) / 2

volume_raw = sign(returns(close, 1)) * clip(RVOL - 1, 0, 1)

score = 0.40 * trend + 0.30 * momentum + 0.30 * volume_score
```

RVOL日线基准为此前20个已完成交易日的成交量均值；分时基准为同一交易时段、纽约本地相同15分钟位置、此前最多20个交易日的成交量均值，至少10个有效历史样本。当前K线不进入自身基准。

分时VWAP按交易日和时段重置，用累计成交额/累计成交量；没有成交额的回放CSV只能得到近似值。日线单根OHLC不被冒充为盘中VWAP，显示为空。

默认70及以上为偏强、30及以下为偏弱，其余为中性。融合区间变化还要求至少两个维度同向确认：偏强对应维度>=60，偏弱对应<=40。同类指标先汇总，不为多条均线重复计票。

## 长期估值与宏观

估值来自 LongPort 的 PeTtmRatio、PbRatio 和 DividendRatioTtm。股息率字段按百分数展示，接口未提供财报观察时点，因此页面显示取数时间。正市盈率可换算成盈利收益率。负市盈率提示复核盈利情况，未返回的数据展示为空。[LongPort 计算指标](https://open.longportapp.com/docs/quote/pull/calc-index)

取美国财政部同一观察日的 3 个月（`BC_3MONTH`）、2 年期（`BC_2YEAR`）和 10 年期（`BC_10YEAR`）国债平价收益率。期限利差 `10Y-2Y = (10 年期 − 2 年期) × 100 bp`，`10Y-3M = (10 年期 − 3 个月) × 100 bp`，未来 12 个月衰退参考概率采用纽约联储单变量 Probit 基准公式 `Φ(-0.5333 - 0.6330 × (10Y - 3M))`（Estrella & Mishkin 1998），比较窗口为向前 21 个有效观测。个股估值除名义股债利差（盈利收益率 − 10Y 名义美债）外，还同时对照扣除通胀后的 10Y TIPS 实际利率利差（盈利收益率 − `DFII10`，回应 Asness 2003 对 Fed Model 通胀错配批评），两者均仅作收益率水平参照、不充当预期回报。当月样本不足时向前取月度记录，最多读取三个月，刷新失败时显示缓存日期及失败状态。[财政部数据接口](https://home.treasury.gov/treasury-daily-interest-rate-xml-feed)

### 宏观水位、流动性与「市场大势」（`macro-1.0.0`）

`signaldesk/macro.py` 定位为**市场整体的风险环境底色**，不做择时信号、不输出 0–100 黑箱总分、不预测指数点位；当前第一阶段仅做展示与脱敏背景透传，**不自动干预个股买卖评级**。

1. **数据源与发布时间严格对齐**：免 API Key 拉取 14 条 FRED 公开序列（`WALCL`、`WTREGEN`、`RRPONTSYD`、`WRESBAL`、`SOFR`、`IORB`、`NFCI`、`ANFCI`、`BAMLH0A0HYM2`、`BAA10Y`、`VIXCLS`、`DTWEXBGS`、`DFII10`、`T10Y3M`），所有缺失标记（`.`）直接剔除、绝不前向填充。每条观测按官方发布时刻截断（`release_at <= now`）：H.4.1（`WALCL`/`WTREGEN`/`WRESBAL`）周三观测于周四 16:30 ET 才可见；`NFCI`/`ANFCI` 周五观测于次周周三 09:30 ET 才可见；`IORB` 当日 09:00 ET；其余日频序列次日 09:00 ET。10 年历史分位仅使用截至当日的因果滚动窗口，样本不足返回空值。
2. **六分项指示灯与阈值**：
   - **① 央行与财政水位**：按周三同日合成 `净流动性 = WALCL/1000 − WTREGEN/1000 − RRPONTSYD`（十亿美元，实测单位：`WALCL`/`WTREGEN` 为百万美元，`RRPONTSYD` 为十亿美元，不跨周前向填充；页面明确标注为「从业者经验口径」），配合银行准备金（`WRESBAL`）与货币市场管道利差（`SOFR − IORB`）。`SOFR > IORB` 或净流动性 13 周收缩超历史滚动 `-1σ` 亮红灯，13 周回升且管道平稳亮绿灯，其余标黄。
   - **② 金融条件（NFCI / ANFCI）**：`NFCI > 0` 且 13 周上行 `>= +0.15` 亮红灯；`NFCI > 0` 或 13 周快速上行标黄；`NFCI <= 0` 且 13 周平稳/转松亮绿灯。
   - **③ 信用利差（ICE 高收益 OAS + Moody's BAA10Y）**：因 FRED 上 `BAMLH0A0HYM2` 授权窗口仅近 3 年，样本不足 2,200 日时自动以 40 年完整的 `BAA10Y` 计算 10 年因果分位并透明标注。13 周走阔 `>= +100bp` 或 10 年分位 `>= 80%` 亮红灯；10 年分位 `< 10%` 标黄警示信用过热（López-Salido et al. 2017）；其余亮绿灯。
   - **④ 利率与曲线**：10Y 实际利率 `DFII10` 近 21 日急升 `>= +50bp` 亮红灯；`10Y − 3M < 0` 或近 6 个月内曾倒挂（提醒「倒挂解除≠风险解除」）或实际利率 21 日上行 `>= +25bp` 标黄；其余亮绿灯。
   - **⑤ 趋势与广度（全市场基准 ETF）**：通过 LongPort 只读获取 `SPY`/`QQQ`/`RSP`/`IWM`/`HYG`/`IEF` 日线并独立存于 `macro-live` 缓存分区（绝不混入用户 `portfolio:live`，也不拿自选池冒充全市场广度）。`SPY` 跌破 MA200 且 `HYG/IEF` 13 周下行或 `QQQ` 同步跌破 MA200 亮红灯；`SPY >= MA200` 且 `RSP/SPY`、`IWM/SPY`、`HYG/IEF` 未显著背离亮绿灯；其余标黄。
   - **⑥ 波动与美元**：`VIX > 25` 或方差风险溢价 `VRP = VIX² − (SPY HV20)² < 0` 亮红灯；广义美元 `DTWEXBGS` 13 周急涨 `>= +5%` 或 `VIX >= 20` 标黄；其余亮绿灯。当信用利差与波动双红灯时额外触发流动性螺旋提示（Brunnermeier & Pedersen 2009）。
3. **四象限与红灯水位**：由「流动性轴（①+②+③ 任一红灯或净得分为负判定偏紧）× 趋势轴（⑤ SPY 相对 MA200）」合成「顺风 / 背离 · 警惕见顶 / 修复 · 观察见底 / 逆风」四象限，并以「红灯数 / 6」展示下行风险水位。刻意不纳入 2020 年口径断点的 M2 与滞后近 1 个月的 FINRA 融资余额。
4. **脱敏边界**：`safe_snapshot()` 白名单仅透传脱敏 `macro_regime`（版本、来源、观测日、四象限、红灯计数、警报、实际利率与六分项灯色/主指标/分位），不含账户与持仓隐私；Codex 保持纯手动触发。

### 夜盘、盘前与盘后独立行情及跳空预警（`ext-1.0.0`）

`signaldesk/extended_hours.py` 融合 LongPort 只读 `enable_overnight=True` 推送与 `SecurityQuote` 中的 `overnight_quote`、`pre_market_quote`、`post_market_quote` 分段行情，严格遵循「展示与前置预警融合、常规日线计算隔离」原则：

1. **常规盘绝对隔离**：盘外实时推送走独立的 `extended_quote` 通道（仅更新 `quote["extended"][session]` 并防乱序旧时间戳回退），**绝不覆盖常规盘主价 `quote["last"]`**，也不混入日线 K 线、均线/MACD/ATR、波浪拐点、`forecast` 点位与 5 级买卖评级或常规盘 `EventEngine.price()` 触发。
2. **活跃盘外时段筛选**：仅采用时间戳严格晚于最近一次常规收盘且不晚于当前时刻（允许 120 秒钟差）的分段作为活跃盘外行情；盘中常规交易时段（`market.session == "regular"`）自动抑制盘外实时预警，仅保留参考记录。
3. **流动性门控与前置预警**：
   - 成交额 `>= 2,000 万美元` 标为「放量充分」，`>= 100 万美元` 标为「成交活跃」，`< 100 万美元` 标为「成交偏薄」。
   - 相对最近常规收盘涨跌幅 `>= ±3%` 为显著跳空、`>= ±6%` 为大幅跳空，并同步预检个人计划失效价/目标价、波浪前低失效位/前高反转位与参考买卖点穿越。
   - 若盘外成交额 `< 100 万美元`（流动性偏薄），预警级别强制降级为 `info` 并显式提示谨防小单虚晃。
4. **脱敏透传**：`safe_snapshot()` 白名单透传独立的 `extended_hours` 摘要（时段、价格、跳空%、成交额、流动性分级与触发明细），供手动 Codex 复核在开盘前结合跳空做预案参考。

日线图、评分及发给模型的技术证据共用同一条计算序列。盘口报价可能比最近的日线收盘更新，两者分别标时。分项贡献为维度分乘以权重，变化为相邻两个有效日线窗口的贡献之差。单日波动、历史不复权拆股跳空都会影响技术指标，不作为盈利或估值变化的证据。

## 独立风险与通知

波动偏高(ATR/price>4%)、偏离MA20超过2ATR、RSI极值、停牌、数据缺失和盘外流动性分别展示。盘外机会额外要求价差<=0.5%、完整15分钟成交额>=100万美元；缺盘口不能自动通过。风险事件不会被机会过滤器压掉。

普通融合事件按同股/仓位类别/周期/时段状态变化产生，同类冷却30分钟，状态及冷却跨重启保存。首次加载建立基线；重连补齐的旧K线标为历史事件，不作为新机会。当前工作台只对纳入长期计划且数量已核对的股票产生提醒。混合仓原有关键价仍归原短线部分，长期复核使用单独设定的价格。

长期仓普通变化进入收盘后10分钟摘要，结构转弱和关键价风险及时处理。盘中使用新鲜的常规时段报价检查长期计划价，收盘复核使用最近完成日线的收盘价。QQ 普通事件等待 30 秒合并，重要风险优先发送。暂停普通提醒后重要风险仍继续。

## 证券分类与 ETF/指数基金专属口径（instruments）

`signaldesk/instruments.py` 通过精确代码映射表与券商名称/代码规则确定性区分单一上市公司（`stock`）与各类基金/ETF：

- **宽基 / 风格 / 区域 / 多资产指数 ETF**（`broad_etf`，如 `QQQ`、`SPY`、`DIA`、`EWT`、`ALLW`）与 **行业/主题 ETF**（`sector_etf`，如 `SOXX`、`XME`、`COPX`、`DRAM`、`SHLD`）及 **商品/债基 ETF**（`commodity_etf`，如 `GLD`、`SLV`、`USO`、`TLT`）：持有成分股篮子或实物/期货资产，券商接口对基金主体计算的 `PE TTM` / `PB` 极易失真（例如实盘中 `QQQ` 返回 `-6.88x`、`SOXX` 返回 `0.79x`、`GLD` 返回 `18.44x`）。系统自动停用单股 PE/盈利收益率/股债利差与「亏损警示」逻辑，改用严格因果计算的**近 1 年（252 日）距 52 周高点回撤**、**近 1 年价格分位**、**20/60 日年化历史波动率（HV20/HV60）**、**近 1 年最大回撤**、**相对 MA200 偏离**及**美国财政部 10Y 美债 21 日变动**进行评估（权重：`技术结构 40%`、`回撤与宏观 25%`、`点位赔率 25%`、`风险控制 10%`）。
- **杠杆与反向 ETF**（`leveraged_etf`，如 `TQQQ`、`QLD`、`SOXL`、`SQQQ`、`SOXS`、`SNXX`、`MUU`、`YINN`、`YANG`）：权重调整为 `技术结构 45%`、`波动与回撤 20%`、`点位赔率 20%`、`杠杆风控 15%`（按年化波动率扣分体现每日再平衡损耗）。其中**反向做空 ETF** 触发专属护栏：行动标签标为「对冲观察」，评级上限封顶 `hold`（不输出长期买入评级）；**正向杠杆 ETF** 评级上限封顶 `buy`（不出 `strong_buy`）并附带复利波动损耗警示。
- **Codex 脱敏隔离**：对 `is_fund = True` 的标的，`safe_snapshot()` 显式透传 `instrument` 与 `fund_metrics`，并将失真的基金主体 `pe_ttm`/`pb`/`earnings_yield_pct`/`yield_gap_pp` 置为 `None`，防止误导模型按公司财报分析 ETF。
- **不复权拆股提示**：因日线采用 `AdjustType.NoAdjust`（不复权）口径，若某标的近 1 年发生拆股（例如 `SOXX` 在 `2026-11-05` 出现不复权单日跳空 `-70.7%`），历史回撤与波动率会包含该次跳空影响。

## 综合研判状态（verdict）与 Codex 分工

每只股票在 `Monitor.stock()` 实时汇总生成确定性的 `verdict` 结构，用于在看板直观回答「当前怎么看、下一步看什么」：

1. **行动标签与优先级（0–9，大白话直译 + `action_meaning` 悬浮释义）**：`0` 跌破止损（已确认收盘 <= 长期失效价）→ `1` 触及目标（收盘 >= 长期目标价）→ `2` 仓位待核（券商股数与本地分类不一致）→ `3` 亏损警示（有效 PE TTM <= 0）→ `4` 转弱警惕（持仓且日线偏弱或风险 >= 2 项）→ `5` 关注买点（观察股且偏强无风险）→ `6` 趋势向好（持仓且偏强无风险）→ `7` 持有观察 → `8` 弱势观望 / 震荡观望 → `9` 数据不足 / 未入长期。
2. **三支柱与通俗维度说明**：同步输出「计划价位」「估值利率」「日线结构」三项紧凑状态，并将趋势（MA200 与 EMA20/50 相对位置）、动量（RSI14 区间与 MACD 柱方向）、量价（RVOL 倍数与涨跌）翻译为直白中文短语。
3. **与 Codex 的职责分工**：上述规则研判在本地毫秒级确定性计算；Codex 总结默认为**纯手动触发**（`CodexSettings.automatic = False`），事件与轮询不会自动调用模型，仅在用户主动点击「生成 Codex 总结」时基于白名单脱敏快照运行。

## 波浪理论与趋势交易结构（wave_trend）

每只股票由 `signaldesk/wave_trend.py` 的 `compute_wave_trend()` 基于连续已确认常规时段日线尾部序列（要求 `>= 60` 根且收盘价与 `ATR14` 有效）执行严格因果计算，输出 `trend`（道氏结构与线性回归平行趋势通道）与 `wave`（艾略特波浪识别与斐波那契测算）：

1. **严格因果摆动拐点（ATR 自适应 ZigZag）**：仅按时间从左到右顺序扫描已确认 K 线，反转阈值取 `max(2.2 × ATR14_i, 4.5% × close_i)`（ATR14 预热期内使用截至当日的因果滚动波幅均值）。只有当后续 K 线反向突破阈值时才确认拐点（`confirmed = True`），当前尚未反转的末端极值单独标记为 `confirmed = False`（图上以虚线与 `*` 区分），严禁未来数据泄露；对相邻同向确认拐点标注道氏结构 `HH`（高点抬高）/ `HL`（低点抬高）/ `LH`（高点降低）/ `LL`（低点降低）。
2. **线性回归平行趋势通道与方向判定**：对最近 `min(len, 90)` 根连续有效常规日线拟合普通最小二乘回归中轨 `mid(t)`，取 `max(1.75 × σ_resid, P88(|resid|), 1.25 × ATR14, 2% × close)` 作为平行通道半宽，确保上下轨满足 `lower < mid < upper`；综合道氏高低点偏向、`MA20/MA50/MA200` 排列与 20 日通道斜率判定 `上升趋势` / `下降趋势` / `箱体震荡`，计算收盘价在通道内的相对分位 `channel_position_pct`、突破确认位 `breakout_level`（前高）与趋势结构防守/反转位 `invalidation_level`（多头前低 / 空头前高）。
3. **艾略特波浪铁律校验与诚实降级**：从尾部因果拐点匹配上升/下降推动浪（`0→1→2→3→4→5` 或进行中的 2/3/4 浪）及三浪调整结构（`0→A→B→C`），严格校验三条核心规则（浪 2 不破浪 1 起点、浪 3 非最短推动浪、浪 4 不与浪 1 价格区间重叠），并输出关键斐波那契测算位（`0.618 / 1.0 / 1.618`）。若近期拐点未形成清晰浪型，绝不强行套用 1–5 浪，诚实标记为 `箱体整理 / 待定浪` 并仅展示客观高低点结构与趋势通道。
4. **脱敏边界与免责属性**：`safe_snapshot()` 仅透传脱敏的 `wave_trend` 方向、浪型阶段与结构位摘要，不含账户与仓位隐私；所有波浪与趋势通道结果仅作客观结构复核参考，不构成投资建议。

## 点位预测与 5 级买卖评级（forecast）

每只股票由 `signaldesk/forecast.py` 的 `compute_forecast()` 基于已确认日线序列、技术摘要、估值/美债研究上下文与长期计划价进行确定性因果计算，输出 `levels`（参考买卖点与防守止损）与 `rating`（5 级综合评级）。

1. **前置因果条件**：仅截取最近一段无中断的连续有效常规时段（`regular`）日线尾部序列，要求连续有效常规日线 `>= 60` 根、`summary.valid == True`、`summary.confirmed_price_available == True`、`close >= 0.05` 且 `ATR14 > 0`。历史不足、缺交易日断档切断预热或行情失效时，诚实返回 `levels.available = False` 与 `rating.code = "unavailable"`（`暂不评级`）。
2. **多锚点点位测算与严格单调约束**：结合已确认 `MA20`、`EMA20`、`BOLL 中/上/下轨`、`MA50`、`MA200`、近 20/60 日高低点、20 日枢轴支撑/阻力（`S1`/`R1`）、斐波那契 `1.618` 扩展位及 `ATR14` 波动倍数，分别锚定参考买点上沿（`buy_high`）、深度买点（`buy_low`）、防守止损（`stop_loss`）、第一卖点（`sell_low`）与第二卖点（`sell_high`）。经 `math.floor(close * 100) / 100` 与两位小数舍入后，强制满足严格单调关系：
   `0 < stop_loss < buy_low < buy_high <= close < sell_low < sell_high`
   同时输出买点中枢 `ideal_buy`、现价盈亏比 `risk_reward_ratio`、买点盈亏比 `entry_risk_reward_ratio` 与位置标记 `position_label`（`接近买点区` / `区间中段` / `接近卖点压力`）。
3. **四因子加权 5 级评级**：
   - 维度与基准权重：`技术结构`（40%，直接取日线 `summary.score`）、`估值利率`（30%，基于有效 `PE TTM`、股息率 `>= 2%` 与 `yield_gap_pp`）、`点位赔率`（20%，基于现价盈亏比与买点贴近度）、`风险控制`（10%，对波动偏高、偏离 `MA20` 超 `2 ATR`、`RSI` 极值与过期风险逐项扣分）。若估值数据缺失或过期，其余有效维度权重自动归一化至 100%。
   - 五级映射：`>= 78` `strong_buy`（强烈买入，5 星）、`>= 64` `buy`（建议买入，4 星）、`>= 46` `hold`（中性观望，3 星）、`>= 32` `reduce`（谨慎减持，2 星）、`< 32` `sell`（建议卖出，1 星），并依估值/利率新鲜度与独立风险数给出置信度（`高` / `中` / `低`）。
4. **保守风控护栏（评级上限封顶）**：
   - 跌破个人计划失效价（`close <= long_plan.stop`）：评级上限封顶为 `reduce`（谨慎减持）。
   - 有效滚动市盈率为负（`pe_ttm <= 0`）：评级上限封顶为 `hold`（中性观望），暂停给出买入评级。
   - 技术处于空头弱势结构（`state == "weak"` 且 `trend < 25`）：评级上限封顶为 `hold`（中性观望），暂停给出买入提示。
5. **脱敏边界与参考属性**：`safe_snapshot()` 仅将脱敏的 `rating`（`code/label/score/confidence`）与 `levels`（`available/buy_low/buy_high/sell_low/sell_high/stop_loss/risk_reward_ratio`）传入 Codex 快照，不含股数、成本与账户标识。输出均带免责说明，仅供复核参考，不构成投资建议。
