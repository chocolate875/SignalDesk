# Finance

- [SignalDesk](SignalDesk/README.md) 是美股长期持仓与自选股复核工具。Windows 用户可双击 [Start-SignalDesk.cmd](SignalDesk/Start-SignalDesk.cmd) 打开看板。
- [NisonCandlestickPatterns](NisonCandlestickPatterns/) 是 TradingView 蜡烛图形态插件，提供[中文脚本](NisonCandlestickPatterns/NisonCandlestickPatterns_CN.pine)和[英文脚本](NisonCandlestickPatterns/NisonCandlestickPatterns.pine)。
